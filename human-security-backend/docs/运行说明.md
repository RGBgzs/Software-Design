## 快速启动

### 1. 数据库准备

数据库已存在（`dream25@47.108.58.107`），只需执行字段升级：

```bash
mysql -h 47.108.58.107 -u root -p dream25 < sql/pir_migration.sql
```

### 2. 编译

```bash
cd E:\develop\claude\human-security-backend
mvn clean compile
```

### 3. 启动

```bash
mvn spring-boot:run
```

访问：http://localhost:8080

## PIR 监测页面（新增）

### 功能概览

1. **统计卡片**：PIR 设备总数、在线设备、今日触发次数、今日告警次数、布防设备数
2. **设备状态卡片**：实时显示每台设备的在线状态、人体感应、布防状态
3. **上报记录表**：分页展示历史人体感应记录，标记告警
4. **操作按钮**：刷新、全部布防、全部撤防、查看告警、AI 分析

### 布防/撤防

- 单个设备：点击设备卡片的「布防」/「撤防」按钮（需二次确认）
- 全部操作：点击「全部布防」/「全部撤防」按钮（需二次确认）
- 布防后检测到人体活动将自动生成告警

### AI 分析

点击「AI 分析」按钮可向 AI 助手发送 PIR 相关查询。

## MQTT Topic 说明

### 订阅 Topic

| Topic | 说明 |
|-------|------|
| `human/device/+/data` | 人体感应设备数据上报 |
| `human/device/+/status` | 设备状态更新 |
| `human/device/+/reply` | 设备指令回复 |
| `pir/device/+/data` | **【新增】PIR 设备数据上报** |
| `pir/device/+/status` | **【新增】PIR 设备状态** |
| `pir/device/+/alarm` | **【新增】PIR 设备告警** |

### 发布 Topic

| Topic | 说明 |
|-------|------|
| `human/device/{deviceCode}/command` | 下发指令（布防/撤防） |

## 注意事项

1. 数据库密码：通过环境变量 `DB_PASSWORD` 注入（`application.yml` 中不含明文密码）
2. MQTT 账号/密码：通过环境变量 `MQTT_USERNAME` / `MQTT_PASSWORD` 注入
2. DeepSeek Key：从环境变量读取，不硬编码
3. 前端接口：使用相对路径 `/api/*`
4. 人脸识别：依赖 Python 微服务，可选
5. HTTPS 语音：需要 HTTPS 环境才可使用浏览器语音识别
6. 华为云 IoTDA：默认关闭，按需启用

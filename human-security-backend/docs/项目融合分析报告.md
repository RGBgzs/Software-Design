## 九、前端融合方案

### 策略

pir-monitor-frontend 是 Vue 3 SPA，**不能直接将 src/ 整体复制**。采用以下策略：

1. **提取设计模式**：从 Vue 组件中提取 HTML 结构、CSS 样式、JS 逻辑
2. **重写为原生 HTML/CSS/JS**：适配主项目的单体 index.html 架构
3. **保持样式一致性**：参考 Element Plus 风格，用 CSS 变量实现
4. **复用已有 API**：前端接口仍使用 `/api/` 相对路径

### 新增前端内容

在 index.html 中新增：

1. **左侧菜单项**：「PIR 监测」（图标：📡）
2. **PIR 监测页面**：
   - 统计卡片（PIR 设备数、在线设备、今日触发、今日告警、布防状态）
   - 实时状态卡片（设备编号、位置、有人/无人、在线状态、最后上报、布防开关）
   - 记录表格（ID、设备编号、位置、感应状态、布防、是否告警、上报时间）
   - 操作按钮（刷新、开启布防、撤销布防、查看告警、AI 分析）
3. **告警联动**：PIR 告警自动出现在告警管理页面
4. **AI 助手集成**：小安可回答问题如"今天有没有人经过"

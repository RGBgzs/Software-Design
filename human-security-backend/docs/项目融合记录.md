## 二、融合前端页面

### 修改文件

| 文件 | 修改内容 |
|------|----------|
| `src/main/resources/static/index.html` | 新增 PIR 监测页面、CSS 样式、JavaScript 函数 |

### 新增前端组件

1. **PIR 监测页面**（`#sec-pir`）
   - 5 个统计卡片（PIR 设备数、在线设备、今日触发、今日告警、布防设备）
   - PIR 设备实时状态卡片网格
   - PIR 上报记录表格（分页）
   - 操作按钮（布防、撤防、刷新、AI 分析）

2. **PIR 设备状态卡片**
   - 设备编号、名称、位置
   - 人体感应状态（有人/无人，带脉冲动画）
   - 在线状态指示器
   - 布防/撤防按钮
   - AI 分析按钮

3. **CSS 样式**
   - `.pir-device-grid` 响应式网格布局
   - `.pir-device-card` 设备卡片样式
   - `.pir-pulse` 人体检测脉冲动画
   - 在线/离线/检测状态颜色区分

4. **JavaScript 函数**
   - `loadPirStats()` - 加载PIR统计数据
   - `loadPirDeviceStatus()` - 加载设备状态
   - `renderPirDevices()` - 渲染设备卡片
   - `pirDefenseOn/Off()` - 单个设备布防/撤防
   - `pirQuickArm/Disarm()` - 批量布防/撤防
   - `loadPirRecords()` - 加载分页记录
   - `renderPirRecords()` - 渲染记录表格

## 三、新增接口

| 方法 | 路径 | 说明 |
|------|------|------|

## 四、新增数据库字段

### device 表新增字段

- `location` VARCHAR(100) - 安装位置
- `device_type` VARCHAR(50) - 设备类型
- `user_id` BIGINT - 关联用户ID
- `online_status` TINYINT - 在线状态
- `human_detected` TINYINT - 人体检测
- `last_report_time` DATETIME - 最后上报时间
- `remark` VARCHAR(500) - 备注

### human_record 表新增字段

- `device_name` VARCHAR(100) - 设备名称
- `location` VARCHAR(100) - 位置
- `is_alarm` TINYINT - 是否生成告警
- `alarm_id` BIGINT - 关联告警ID
- `raw_data` TEXT - 原始上报数据
- `create_time` DATETIME - 创建时间

## 六、冲突解决

| 冲突 | 解决方案 |
|------|----------|
| DeviceController 路径冲突 | 以主项目为准，新功能走 PirController |
| AlarmController vs AlarmRecordController | 以主项目 AlarmRecordController 为准 |
| MQTT 实现方式不同 | 主项目用 Paho 原生，smart-security-backend 用 Spring Integration，保持主项目方式 |
| Device 表结构差异 | 用 ALTER TABLE ADD COLUMN 升级 |
| HumanRecord 表字段差异 | 用 ALTER TABLE ADD COLUMN 升级 |

---

## 七、未融合内容及原因

| 内容 | 原因 |
|------|------|
| JWT 认证 | 主项目未使用 |
| Redis | 主项目未使用 |
| RabbitMQ/AMQP | 主项目未使用 |
| Spring Integration MQTT | 主项目用 Paho 原生已够用 |
| H2 数据库 | 主项目用 MySQL |
| WebSocket 实时推送 | 复杂度高，当前用 HTTP 轮询替代 |
| Vue/React 框架 | 主项目是原生 HTML 单体架构 |
| CameraController | 主项目前端人脸识别已有摄像头功能 |
| 前端 Element Plus | 不引入外部 CDN |
| Python 5000 直接调用 | 主项目已有类似代理实现 |
| 前端 MQTT WebSocket 连接 | 浏览器端暂不需要 MQTT 直连 |

===============================================
  智慧安防 AI 语音系统 — 使用说明
===============================================

一、环境要求

  · Java 17+
  · Maven 3.6+
  · Python 3.9+
  · Node.js 18+
  · MySQL 数据库（已配置远程库：47.108.58.107:3306）
  · Chrome 浏览器（必须，语音识别需要 Web Speech API）

二、启动步骤

  1. 双击 setup.bat — 检查环境是否就绪

  2. 双击 start.bat — 一键启动全部服务
     （首次运行自动安装前端依赖，然后等待 Python → 后端 → 前端就绪，约 2 分钟）

  3. 浏览器打开 http://localhost:5177

三、测试账号

  admin     / 123456   （管理员）
  aaa       / 123      （居民）
  guard     / 123456   （保安）

四、服务端口

  前端 Vue     :5177
  后端 Java    :8080
  人脸 Python  :5000

五、常见问题

  Q: 语音识别没反应？
  A: 必须使用 Chrome 浏览器，确认麦克风权限已授权

  Q: 启动时提示 Python 错误？
  A: 运行 pip install flask flask-cors requests pymysql
     确认 E:\Downloads\face\ 目录下的模型文件完整

  Q: 人脸识别提示"服务未连接"？
  A: 确认 Python 服务已启动（端口 5000），等待约 40 秒模型加载

  Q: start.bat 卡在"等待人脸服务"？
  A: Python 加载大模型需要时间，首次加载约 30-60 秒
